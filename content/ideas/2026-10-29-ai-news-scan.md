## 1. Google announces Gemini 4 Carbon, a frontier model aimed at cybersecurity and long-horizon coding
- What: Google says Carbon is its strongest model, ranking #1 on Artificial Analysis Intelligence Index v5.0 (59), with SEC-bench Pro 88.2% (finding vulns), ExploitGym 54.8% (exploitation) and CWE-bench 71.0% (patching), and reduced misalignment and fabrication rates in Google's own live coding environments. It comes two weeks after Gemini 4 Argon. Access starts this week with a subset of cyber defenders, then trusted partners via the Fairwind Program, then developers and consumers "as soon as possible." Intro price matches Argon at $2 / $10 per 1M input/output tokens, rising to $4 / $20 after the intro period. Google says it is taking part in the U.S. government's voluntary pre-release testing process.
- Sources: https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/ , Reuters via https://www.investing.com/news/stock-market-news/google-launches-gemini-4-carbon-ai-model-with-cybersecurity-focus-4980426
- Take: The headline isn't the leaderboard, it's the gate. A model that's good at exploitation ships to defenders first, and the price is announced before most of us can call it. Benchmarks are Google's own numbers; nobody outside the cohort can verify them yet.

## 2. GitHub Copilot Fusion is GA: you pick an effort level, not a model
- What: Announced at GitHub Universe on Oct 28. Fusion routes each task across models with three patterns (Single; Cascade, where a cheap model drafts and escalates if a quality check fails; Critique, where a second model reviews and the first revises). Effort levels are Standard, High, Max. GitHub says Fusion Max scored 60 on the Artificial Analysis Coding Agent Index, within two points of Claude Code with Opus 5.5 Max, at about half the API cost per task, about half the tokens and about 40% less time. Billed per model used at standard rates, with a limited-time 30% discount on paid plans. Available in VS Code, the Copilot app, Copilot CLI and JetBrains. Local-model routing shipped as an experimental preview the same day.
- Sources: https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion/ , https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/
- Take: "Which model should I use?" is turning into a setting the tool decides for you. Cascade is the pattern every builder can steal today: cheap model first, escalate on a failed check. The cost claim is GitHub's own and worth testing.
- Content idea (post/thread): "Stop picking models. Here's the routing trick GitHub just productized." Explain Single / Cascade / Critique in three lines each, then how I'd do Cascade in my own pipeline (cheap draft, check, escalate). Cite GitHub's numbers as theirs.

## 3. GitHub Agentic Workflows is GA: coding agents inside GitHub Actions, written in Markdown
- What: Open-source project from GitHub Next, GA Oct 28 on GitHub Free, Team and Enterprise. You write a workflow in natural-language Markdown and it compiles to standard Actions YAML; it can run Copilot or another coding agent for things like issue triage, CI failure analysis, docs updates and test writing. Agents are read-only by default, run in a sandboxed container behind the Agent Workflow Firewall, outputs go through a "safe outputs" check and a threat-detection job scans proposed changes. GA adds self-hosted ARC runner support, `gh aw forecast` for AI credit spend, per-workflow model providers and routing, and micro-VM isolation options. The default Copilot CLI engine requires a Copilot license.
- Sources: https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available/ , https://www.aiandtech.news/article/github-agentic-workflows-is-generally-available
- Take: This is the "agent sandboxes are the new hosting" thread from Oct 27 showing up inside the most-used CI on earth: read-only by default, firewall on egress. It's also the most buildable item today, since Orb Builds' site repo already lives on GitHub.

Lumin adds one agentic workflow to the Orb Builds site repo (for example, a read-only weekly report or CI-failure explainer), runs `gh aw forecast` on camera to show the expected cost, and reports what the agent did and didn't do.
