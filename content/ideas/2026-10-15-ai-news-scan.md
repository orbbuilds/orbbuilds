## 1. StepFun drops Step 5 Preview weights on the date it promised
- **Summary:** On Oct 15, 2026 (shortly after midnight UTC), StepFun published Step 5 Preview open weights on Hugging Face and ModelScope, matching the Oct 15 date it set when the API launched Sept 20. Specs from the model card: sparse MoE, **600B total / 27B active**, up to **1M context** and up to **1M max output**, positioned as a flagship for agentic work (software engineering, long-horizon tool use, knowledge work, with a finance focus). Checkpoints: `stepfun-ai/Step-5-Preview` (FP8), `Step-5-Preview-BF16`, and `Step-5-Preview-NVFP4`. Serving recipes cover vLLM (`vllm/vllm-openai:step-5-preview`), SGLang, and Transformers; FP8 fits roughly one 4×B300 or 8×H200 node. License is **StepFun Model License 1.0** (Apache-style with commercial gates: device OEMs and MaaS providers over $20M revenue need a separate commercial license; large products must show "Powered by StepFun AI"; models trained materially on its outputs are treated as derivatives). API stays listed around **$1.00 / $2.70** per 1M tokens. The spec table lists text+image in / text out (the intro also mentions video). Benchmarks on the card are vendor-framed (GDPval-AA dated Sept 20); treat as claims until independent evals land.
- **Sources:** [Hugging Face: Step-5-Preview](https://huggingface.co/stepfun-ai/Step-5-Preview), [Post-Cutoff write-up (Oct 15)](https://postcutoff.com/e/2026-10-15-stepfun-step-5-preview-open-weights/), [When It Ships](https://whenitships.com/)

This is not a laptop model, and "open" here still means commercial gates plus a distillation clause. Promising a date and hitting it is rare; I respect that.

## 3. OpenAI Ultrafast: near-frontier brains at a speed tax
- **Summary:** OpenAI's docs now describe **Ultrafast** as the fastest API service tier, broadly available for **GPT-6 Astra** and **GPT-6.1 Sol** via `service_tier: "ultrafast"` on the Responses API (WebSocket strongly recommended for agent loops). When It Ships / tracker coverage frames Ultrafast for GPT-6.1 Sol as near-Astra intelligence at up to ~8× Sol Standard speed, with API pricing cited around **$12 / $60** per million input/output tokens (confirm against the live Ultrafast pricing table before quoting on camera). Ultrafast has **separate rate limits** from Standard/Fast; Sol Ultrafast supports US/EU data residency; Astra Ultrafast is US residency + global. Codex / ChatGPT Work access for Sol Ultrafast is described in tracker posts as Pro 500 plus eligible Enterprise/Edu (Enterprise admins enable). Use when latency beats the higher bill.
- **Sources:** [OpenAI docs: Ultrafast mode](https://developers.openai.com/api/docs/guides/ultrafast-mode), [When It Ships](https://whenitships.com/), [OpenAI pricing docs](https://developers.openai.com/api/docs/pricing)
- **Take:** Speed tiers are the adult version of "just use the smart model for everything." Agents that tool-call every two seconds waste more time on the network than on tokens — which is why the docs push WebSockets. For an underdog channel, the story is the spreadsheet: same task, Standard vs Ultrafast, wall-clock and dollars.
- **Content idea:** Builder short: **"Is Ultrafast Worth 3× the Bill?"** Run one identical Orb Builds agent chore on Sol Standard and Sol Ultrafast (WebSocket both ways), show latency and cost side by side, and pick a rule of thumb for when I'd pay up (live chat, tight render window) vs. stay cheap (overnight batch).
